# 💎 مغامرة جواهر الآجرومية ثلاثية الأبعاد (3D Al-Ajurrumiyyah Gem Maze & X/O Game)

**إعداد:** الأستاذ أحمد حسن  
**تحت إشراف:** د. محسن — بدورة المعلم الحر

لعبة تعليمية تفاعلية ثلاثية الأبعاد (WebGL / Three.js) للأطفال والطلاب في **شرح الآجرومية لفضيلة الشيخ محمد بن صالح العثيمين** (من الصفحة 1 إلى الصفحة 150).

## ✨ المميزات الرئيسية
- **ثلاثية الأبعاد بالكامل (3D WebGL):** ليست 2D، بل تعتمد على محرك `Three.js` لشخصية ثلاثية الأبعاد، ومتاهة البحث عن الجواهر ثلاثية الأبعاد (3D Gem Hunt Maze)، ولعبة (3D X & O).
- **70 سؤالاً شاملاً بدون تكرار:** مستخرجة بدقة من صفحات الكتاب (1 إلى 150: الكلام وأقسامه، باب الإعراب، باب معرفة علامات الإعراب).
- **توزيع ذكي ومتغير للخيارات:** خوارزمية تمنع ثبات الخيار الصحيح في موضع واحد وتمنع تكرار موضعه في السؤال التالي.
- **دعم 6 لغات عالمية بزر تبديل فوري في الصفحة الرئيسية:** العربية 🇸🇦، الإنجليزية 🇬🇧، الإسبانية 🇪🇸، الأردو 🇵🇰، الصينية 🇨🇳، والفرنسية 🇫🇷.
- **نظام الجوائز والنقاط:** كل لعبة (متاهة أو X/O) تمنح الفائز **نجمة ذهبية (⭐)**، وكل سؤال اختيار من متعدد يمنح **3 نقاط (🎯)**.
- **دعم طالب واحد أو طالبين أو أكثر:** إمكانية اختيار عدد الطلاب وكتابة أسمائهم في بداية اللعبة مع لوحة صدارة حية.

## 🚀 طريقة النشر على GitHub Pages
1. أنشئ مستودعاً جديداً (New Repository) على حسابك في GitHub.
2. ارفع ملف `index.html` وملف `README.md` إلى المستودع.
3. اذهب إلى **Settings** > **Pages** واختر الفرع `main` ثم اضغط **Save**.
4. ستعمل اللعبة مباشرة عبر رابط GitHub Pages الخاص بك!
